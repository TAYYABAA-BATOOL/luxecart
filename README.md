# 🛍️ Modern E-Commerce Web Application

LuxeCart is a full-featured, lightning-fast e-commerce web application built to provide a seamless online shopping experience. From browsing curated product collections to secure user authentication and smooth cart management, LuxeCart handles it all with style.

---

## ✨ Features

* **User Authentication:** Secure user registration and login powered by JSON Web Tokens (JWT) and encrypted passwords.
* **Dynamic Product Catalog:** Explore a wide range of luxury products with real-time stock and pricing.
* **Interactive Shopping Cart:** Easily add, remove, and update items in your cart on the fly.
* **Order Management:** Place orders smoothly and track your purchase history.
* **Responsive UI:** Designed with a clean, modern aesthetic that looks stunning on mobile phones, tablets, and desktops.

---

## 🛠️ Tech Stack

**Frontend:**
* React.js
* HTML5 / CSS3 / JavaScript (Tailwind CSS)

**Backend:**
* Node.js & Express.js
* MySQL (`mysql2`)
* JWT for secure sessions
* Bcrypt.js for password hashing
